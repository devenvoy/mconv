# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The `mconv` maintainers take security seriously. If you discover a security vulnerability in `mconv`, please follow these steps:

1. **Do not open a public issue.**
2. Send a detailed report via email to **security@mconv.org** or use GitHub's private security advisory disclosure.
3. Include the following details in your report:
   - Operating system and version
   - Rust and FFmpeg versions
   - Exact steps to reproduce or proof-of-concept
   - Potential impact of the vulnerability

## Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an initial assessment and timeline for a patch within 5 business days.
- Once fixed, a security release will be published and credit will be given to the reporter (unless anonymity is requested).
